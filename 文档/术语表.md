## 一、风格规约

| 项 | 约定 | 理由 |
|---|---|---|
| 语言 | 现代汉语 | 读者要能顺读 |
| 禁用词 | 是故、爾時、云何、何以故、如是我聞、一時佛住 | 文言腔会把现代译文拖回半文半白 |
| 引号 | **保留原文的「」『』**，不改 “” | 更贴原文；且引号常跨段，改动容易错配 |
| 省略号 | 保留原文的「……」，不展开 | 展开等于替原文补句 |
| 校勘符号 | 去掉 `[ ] { }`，只译正文 | 那是校勘信息，不是经文 |
| 数字 | 保留原文，只转简体（八萬四千→八万四千） | 不换算成阿拉伯数字，保持经卷感 |
| 人名地名 | 照抄，只转简体 | 不音译改写；生僻字（波罗㮈）保留原字 |
| 拿不准 | 直译 | 宁可笨，不可加戏 |
| 未定术语 | **照录原文**（如五受阴） | 不硬造译名，等定了再统一改 |

## 三、定型句

| 原文 | 译 |
|---|---|
| 如是我聞： | 我听到的是这样的： |
| 一時，佛住 X。 | 有一次，佛陀住在 X。 |
| 爾時，世尊告諸比丘： | 那时，世尊对众比丘说： |
| 時，諸比丘聞佛所說，歡喜奉行。 | 那时，众比丘听了佛陀所说的，欢喜地奉行。 |
| 我生已盡，梵行已立，所作已作，自知不受後有。 | 我的出生已到尽头，清净的修行已经圆满，该做的都已做完，自己知道不再受生。 |
| X是我、異我、相在 | X是我、X之外另有我、我与X相互包含 |
| 不受後有 | 不再受后有（保留「后有」） |
| 於意云何 | 你怎么想 |

其中「如是我聞」「一時，佛住…」「聞佛所說，歡喜奉行」这几条已做成**本地字典**
（`工具\导出译文批次.py` 里 `BOILER`），命中就直接给译文，**不花翻译钱**。

「我生已盡」按 2026-11-14 定的 **B 案全白话**；2026-11-15 又把 38 段
「这是我的最后一生…」变体统一成 B，现共 113 段使用 B 句。
「歡喜奉行」当时定**先不改**，保留现有「欢喜地奉行 / 欢喜信受」两种措辞。

## 五、已定的三条（2026-11-14）

1. **五受陰 → 照录「五受阴」**，不译。原则：术语没有定译就保留原文，不硬造译名。
2. **使 → 烦恼**（通俗优先；「随眠」留给注释解释）。
3. **X是我、異我、相在** → 「**X是我、X之外另有我、我与X相互包含**」。
   三分句对应：① X 本身被当成我 ② X 之外另有一个我 ③ 我与 X 相互包含而共同存在
   （我中有 X、X 中有我）。否定式作「X不是我、不是X之外另有我、X与我也不相互包含」。
