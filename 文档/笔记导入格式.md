# 笔记导入格式

## 1. 手写 Markdown 模板

见仓库根目录 [`笔记模板.md`](../笔记模板.md)。

```
## SA.1

### 第 6 段

笔记内容。

## SA.8

没有段号时作为经后笔记。
```

- 经号必须是软件内已有的；
- `### 第 N 段` 可省略；
- 文件用 UTF-8 保存；
- 在「設定 → 我的資料 → 匯入資料」选择文件。

## 2. 标准 JSON：`agama-note-pack`

```json
{
  "v": 1,
  "kind": "agama-note-pack",
  "meta": {
    "name": "我的笔记",
    "author": "姓名或昵称",
    "license": "未指定"
  },
  "notes": [
    { "k": "SA.1", "b": 6, "text": "这一段的想法", "quote": "『我生已尽…』" },
    { "k": "SA.8", "post": true, "text": "整经读完后的总评" }
  ]
}
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `k` | 是 | 经号，如 `SA.1`、`SN.22.12` |
| `b` | 段笔记必填 | 段号；不确定时省略并设 `post:true` |
| `text` | 是 | 笔记正文 |
| `quote` | 否 | 摘录，可留空 |
| `post` | 否 | `true` 表示经后笔记 |
| `folder` | 否 | 目标文件夹 id；普通用户可省略 |

## 3. 现有可导入类型

- `agama-userdata`：本软件完整资料备份；
- 带 `entries` 的笔记包：作为新注释来源或合并；
- `agama-pali-zh`：巴利直译包；
- `agama-note-pack` / Markdown 模板：本页新增；
- `agama-translation`：译文导出包（目前仍需复核导入分支）。

## 4. 批量整理建议

让 AI 输出 Markdown 模板时，要求：

- 只输出模板，不输出解释；
- 不编造经号；
- 同一经同一段只保留一条；
- 不确定段号时用经后笔记；
- 不改经文原文，只整理用户笔记。
